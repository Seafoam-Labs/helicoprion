# helicoprion-workloads

The `Workload` trait, the runner and the built-in workloads of [helicoprion](https://github.com/Seafoam-Labs/helicoprion), a
scheduler-focused CPU benchmark for Linux.

This crate is a part of the `helicoprion` binary, published so that
`cargo install helicoprion` works. It is released together with it and has
no stable API of its own: every release may change it, and the crates depend
on exactly one another's version.
